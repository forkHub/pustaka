# 📖 Dokumentasi BASIK

## Gambaran Umum
**BASIK** adalah kumpulan perintah JavaScript sederhana untuk belajar pemrograman interaktif berbasis kanvas.  
Dirancang khusus bagi pemula, guru, maupun siapa saja yang ingin memahami dasar pemrograman visual dengan cara praktis dan menyenangkan.

**Prinsip BASIK:**
- **Perintah sederhana** ✅  
- **Tanpa server** 📐  
- **Memancing kreativitas** 🔥  
- **Umpan balik langsung** ⚡  
- **Fungsi bawaan siap pakai** 🧠  
- **Struktur proyek siap digunakan** 📦  
- **Contoh variatif** 🎨  
- **Bisa luring/daring** 🌐  
- **Berjalan di mobile/desktop** 📱  

---

## Cara Pemakaian
- **Daring** → buka melalui alamat web.  
- **Luring** → jalankan file `editor.html` di browser.  

Contoh aplikasi sederhana:
```js
mulai();
stempel("roket");
```
- `mulai()` → memulai aplikasi (wajib dipanggil pertama). Perintah ini berguna untuk menyiapkan kanvas, dan segala sesuatu yang dibutuhkan untuk mulai membuat applikasi.

- `stempel("roket")` → menempelkan gambar ke kanvas.  

👉 Hasilnya: gambar roket langsung muncul di kanvas.

Bayangkan kamu baru membuka kanvas kosong. Begitu kamu memanggil `mulai()`, kanvas itu aktif dan siap digunakan. Lalu dengan `stempel("roket")`, seolah-olah kamu mengambil stempel bergambar roket dan menempelkannya ke layar. Hasilnya, roket langsung muncul tanpa perlu pengaturan tambahan.

---

## Manajemen Gambar

Perintah `stempel()` adalah perintah sederhana untuk menempelkan gambar. Namun perintah ini memiliki banyak keterbatasan, misalnya: dengan perintah ini kita tidak bisa mengubah ukuran gambar, rotasi dll. 
Untuk mengatasi hal ini kita akan menggunakan perintah baru yaiut `muatGambar()`

Gambar dimuat dengan `muatGambar()`. Setelah dimuat, gambar bisa diatur melalui properti atau fungsi ringkas.

Contoh dengan property;

```
mulai();
let roket = muatGambar("roket");
roket.x = 400;
roket.y = 300;
roket.panjang = 90;
roket.lebar = 70;
stempel(roket);
```

**Properti penting:**
- `x`, `y` → posisi  
- `alpha` → transparansi  
- `panjang`, `lebar` → ukuran  
- `rotasi` → sudut putar  
- `tipeDrag` → tipe interaksi drag  
- `frame` → animasi spritesheet  


Atau kita bisa memanipulasi gambar dengan perintah yang lebih ringkas:

Contoh:
```js
mulai();
let roket = muatGambar("roket");
posisiGambar(roket, 400, 300);
ukuranGambar(roket, 90, 70);
stempel(roket);
```

Dengan menggunakan object gambar, maka sekarang ceritanya jadi lebih detail. Kamu memanggil `muatGambar("roket")` untuk membuat sebuah objek roket. Objek ini seperti mainan yang bisa kamu atur sesuka hati. Kamu meletakkannya di koordinat (400,300), lalu mengecilkan ukurannya menjadi 90×70. Setelah semua diatur, kamu menempelkan roket itu ke kanvas. Kini roket muncul tepat di posisi yang kamu tentukan.

## Interaktivitas
BASIK mendukung aplikasi dinamis dengan fungsi bawaan untuk **update**, **mouse**, **keyboard**, dan **touch**.

Contoh animasi sederhana:
```js
mulai();
let roket = muatGambar("roket");
pusatGambar(roket, 32, 46);
posisiGambar(roket, 400, 300);

function update() {
    bersihkanLayar();
    roket.rotasi++;
    stempel(roket);
}
```

Contoh drag:
```js
mulai();
let roket = muatGambar("roket");
roket.tipeDrag = 1;

function update() {
    bersihkanLayar();
    roket.rotasi++;
    stempel(roket);
}
```
