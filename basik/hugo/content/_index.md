# BASIK - Belajar koding untuk pemula

> Web ini masih dalam tahap pengembangan, Fungsionalitas utama sudah berjalan, kesalahan dan perubahan bisa terjadi tanpa pemberitahuan lebih dahulu.

---

## ✨ Tentang BASIK

BASIK adalah sebuah platform pembelajaran koding dengan pendekatan interaktif dan permainan. Murid bisa belajar koding sambil bermain membuat applikasi interaktif, games, simulasi, dll.

---

## 🔧 Prinsip Desain

- Perintah yang disederhanakan ✅
- Tanpa install server 📐
- Memancing kreatifitas 🔥
- Umpan balik langsung ⚡
- Fungsi bawaan siap pakai 🧠
- Struktur proyek siap digunakan 📦
- Contoh yang variatif 🎨
- Dapat digunakan secara luring/daring 🌐
- Jalan di mobile ataupun desktop 📱
